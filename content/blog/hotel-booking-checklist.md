# 호텔에서 출장마사지 이용할 때 체크리스트

호텔 이용 시에는 자택과 달리 출입/주차/동선 정보가 중요합니다. 아래 5가지를 먼저 확인하면 예약 진행이 훨씬 안정적입니다.

## 1. 호텔명 + 객실 정보 전달 범위 확인

- 호텔명은 필수 전달
- 객실번호는 보안상 필요한 시점에만 공유

## 2. 출입 동선 확인

- 로비 출입 방식
- 엘리베이터 이용 가능 여부
- 객실층 접근 절차

## 3. 주차 및 하차 동선 확인

- 차량 진입 위치
- 단기 하차 가능 구역
- 주차 등록 필요 여부

## 4. 이용 가능 시간 확인

- 호텔 내 정숙 시간대 확인
- 예약 시간과 체크아웃/체크인 일정 충돌 여부 확인

## 5. 코스와 시간 미리 확정

- 이동 포함 일정이므로 코스 변경 여지를 최소화하는 것이 효율적

## 자주 묻는 질문

### Q1. 호텔에서도 후불제로 이용 가능한가요?
네. 기본 원칙은 동일하게 서비스 완료 후 결제입니다.

### Q2. 심야 시간에도 호텔 이용 가능한가요?
가능 여부는 호텔 정책과 시간대에 따라 안내됩니다.

### Q3. 준비물이 필요한가요?
일반적으로 별도 준비물은 거의 없으며, 위치/출입 정보가 가장 중요합니다.
