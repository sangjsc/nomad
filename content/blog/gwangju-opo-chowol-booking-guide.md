# 경기도 광주 오포1동·오포2동·신현동·능평동·초월읍 예약 가이드

경기도 광주시는 생활권이 분산되어 있어 같은 시 안에서도 체감 동선이 다릅니다.  
오포1동·오포2동·신현동·능평동(옛 오포읍 생활권)과 초월읍은 특히 정확한 주소 전달이 예약 가능 여부 확인에 중요합니다.

## 오포1동·오포2동·신현동·능평동 문의 포인트

- 단지명/상가명 포함한 주소 전달
- 차량 진입 동선 간단 안내
- 야간 주차 가능 여부 확인

## 초월권 문의 포인트

- 도로명 주소와 함께 인근 랜드마크 전달
- 건물 출입 방식(공동현관/직통) 전달
- 희망 시간 2안 제시

## 광주시 문의 시 자주 누락되는 정보

1. “광주”만 말하고 경기도 여부를 빼는 경우
2. 건물명 없이 번지 정보만 전달하는 경우
3. 시간대만 요청하고 코스를 나중에 정하는 경우

## 빠른 안내를 위한 권장 순서

주소 → 희망 시간 → 코스/이용 시간 → 주차 가능 여부  
이 순서로 전달하면 문의 왕복 횟수가 줄어듭니다.
